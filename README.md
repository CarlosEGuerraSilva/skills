# Skills

A collection of skills I use in my day-to-day work with AI agents.

Some of these skills were written manually, while others were generated with LLMs and then reviewed or refined by hand. The table below documents how each one was created.

| Skill | How it was created |
| --- | --- |
| `dashboard-design` | Written manually, then translated and refined with GPT 6 Astra xhigh |
| `heroui-v3-design-guide` | Generated with GLM 5.3 Flash, rewritten with GPT 6 Astra Pro with [poteto's unslop skill](https://github.com/cursor/plugins/blob/main/pstack/skills/unslop/SKILL.md) |

I’ll keep these skills updated as time allows, so check back occasionally for changes and new additions.

Contributions, fixes, and improvements are welcome.
