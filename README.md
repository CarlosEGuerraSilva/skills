# Skills

A collection of skills I use in my day-to-day work with AI agents.

Some of these skills were written manually, while others were generated with LLMs and then reviewed or refined by hand. The table below documents how each one was created.


| Skill                    | Purpose                                                                                                                                                                                                                                  | How it was created                                                                                                                                                   |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `dashboard-design`       | Understand and improve the functionality of a usability-focused application interface or dashboard, correct anti-patterns and poor wording and ensure harmonious integration with any existing UI libraries or patterns in the codebase. | Written manually, then translated and refined with GPT 6 Astra xhigh                                                                                                 |
| `heroui-v3-design-guide` | Understand HeroUI design patterns, follow documented recommendations, and improve the use of roles and components.                                                                                                                       | Generated with GLM 5.3 Flash, rewritten with GPT 6 Astra Pro with [poteto's unslop skill](https://github.com/cursor/plugins/blob/main/pstack/skills/unslop/SKILL.md) |
| `senior-research`        | Conduct extensive and in-depth research on any topic in an organized and neutral manner, preventing biases or any misalignment that could affect the post-analysis or subsequent work. Not recommended for quick searches.               | Handwritten, rewritten with Opus 4.6, and further refined with Sonnet 5.5 and GPT-6 Astra Pro.                                                                       |


I’ll keep these skills updated as time allows, so check back occasionally for changes and new additions.

Contributions, fixes, and improvements are welcome.
